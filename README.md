### Projetos

**Drone controlado por gestos**
Reconhecimento de mão com visão rodando offboard, enviando comando por rádio. PCB projetada do zero, sem placa de desenvolvimento pronta.
`Python` · `OpenCV` · `PCB`

**Robô de mesa com interação por voz**
Pipeline STT → LLM → TTS via Groq, firmware FreeRTOS dual-core no ESP32-S3 e sistema paramétrico de expressões em OLED.
`ESP32-S3` · `FreeRTOS` · `Node.js`

**Réplica funcional do WALL-E**
Arquitetura de dois controladores: ESP32 para display e WiFi, Arduino Uno para motores e servos, comunicando por UART em protocolo próprio.
`ESP32` · `Arduino` · `UART`

**Display óptico AR monocular**
HUD vestível com microdisplay OLED, combinador plano e colimador refrativo separado. Projeto de óptica, alinhamento e montagem.
`Óptica` `Prototipagem`

**Controle de acesso RFID**
Cadastro por cartão admin, log com timestamp em cartão SD e gerenciamento remoto por app.
`ESP32` · `RFID` · `Android`

**Classificação de resíduos**
Identificação de recicláveis por imagem, base para triagem automatizada em esteira.
`Python` · `YOLO` · `OpenCV`

**Kit de robótica para oficinas — LARP**
Kit de baixo custo projetado para produção em escala, usado em oficinas de montagem para iniciantes.
`Hardware` · `Produto`
